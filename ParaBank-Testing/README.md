# 🤖 ParaBank – Automation Testing Project

## 📌 Project Overview

ParaBank is a web-based banking application used for practicing automation testing.

## 🎯 Project Objective

The objective of this project was to automate important banking application functionalities and verify that the application works as expected.

## 🛠️ Technologies & Tools Used

- Java
- Selenium WebDriver
- Maven
- TestNG
- Eclipse/IDE
- Git & GitHub

## 🧪 Automation Testing Performed

- Registration Automation
- Login Automation
- Account Creation
- Fund Transfer
- Bill Payment
- Account Overview
- Transaction Verification
- Logout

## 🔄 Automation Activities

- Created automation scripts
- Identified web elements
- Used Selenium WebDriver
- Executed automated test cases
- Validated expected and actual results
- Generated test execution results
