# 🔌 API Testing – Postman Project

## 📌 Project Overview

This project demonstrates API testing using Postman to verify API functionality, responses, status codes, and data.

## 🎯 Testing Objective

The objective of this project was to:

- Understand REST APIs
- Send API requests using Postman
- Validate API responses
- Verify HTTP status codes
- Test positive and negative scenarios
- Create automated API test validations

- Positive Testing
- Negative Testing
