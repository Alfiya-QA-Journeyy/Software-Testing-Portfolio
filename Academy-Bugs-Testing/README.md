# 🧪 Academy Bugs – Manual Testing Project

## 📌 Project Overview

Academy Bugs is a web application used to practice manual software testing and identify functional and UI defects.

## 🎯 Testing Objective

The objective of this project was to:
- Identify defects in the application
- Create detailed bug reports
- Verify expected vs actual results
- Practice defect life cycle
- Understand severity and priority

## 🛠️ Testing Performed

- Functional Testing
- UI Testing
- Negative Testing
- Regression Testing
- Exploratory Testing

## 🐞 Defects Identified

I identified and documented **25 defects** during testing.

Each defect was documented with:
- Bug ID
- Title
- Module
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Screenshot
