# 🏦 ParaBank – Manual Testing Project

## 📌 Project Overview

ParaBank is a web-based banking application used to practice manual software testing and validate different banking functionalities.

## 🎯 Testing Objective

The objective of this project was to:

- Verify application functionality
- Identify functional and UI defects
- Create and execute test cases
- Perform positive and negative testing
- Document defects with proper details

## 🛠️ Testing Performed

- Functional Testing
- UI Testing
- Negative Testing
- Regression Testing
- Exploratory Testing

## 📋 Modules Tested

- Registration
- Login
- Account Creation
- Fund Transfer
- Bill Payment
- Account Overview
- Transaction History
- Logout

## 🐞 Testing Activities

- Test Case Design
- Test Scenario Creation
- Bug Identification
- Bug Reporting
- Retesting
