# 🧘 AI Yoga & Wellness Coach

## 📌 Project Overview

AI Yoga & Wellness Coach is an academic project developed to provide yoga and wellness-related guidance using Python and a logical database.

The main objective of this project was to develop an application that combines Python programming with database concepts to manage and provide wellness-related information.
