# 🚗 Buggy Cars – Manual Testing Project

## 📌 Project Overview

Buggy Cars is a web application used to practice manual software testing, with a focus on registration functionality and form validation.

## 🎯 Testing Objective

The objective of this project was to:

- Verify the registration functionality
- Create and execute test cases
- Validate mandatory fields
- Test positive and negative scenarios
- Identify defects in the registration process
- Verify expected vs actual results

## 🛠️ Testing Performed

- Functional Testing
- UI Testing
- Negative Testing
- Validation Testing
- Registration Testing
- Exploratory Testing

## 🧪 Test Cases

I created and executed **20 test cases** for the registration page.

The test cases covered:

- Valid registration
- Blank mandatory fields
- Username validation
- Password validation
- Confirm password validation
- Existing username
- Special characters
- Username spaces
- Password character validation
- Register button validation
- Password masking
- Cancel button
- Keyboard navigation
- Enter key functionality

## 🐞 Defects Identified

During testing, **2 defects were identified**.

Each defect was documented with:

- Bug ID
- Bug Title
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
